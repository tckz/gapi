# gapi

Example for invoking Google API.
https://github.com/google/google-api-go-client/


## Command line

```text
$ gapi [global options] <command> <sub-command>

Options:
  -service-account string
        /path/to/service-account.json
  -version
        show Version
```

# Build

```
$ make
```

## Requirement

* Go 1.26
* git
* make
